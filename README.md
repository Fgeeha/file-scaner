# Folder Scanner

Небольшое приложение на **PyQt5** для сканирования содержимого папки.
Программа проходит по всем вложенным каталогам и записывает структуру
папок и файлов в текстовый файл `res.txt`.

## Возможности
- выбор сканируемой папки через графический интерфейс;
- перечисление файлов с отображением расширения и размера;
- выбор единиц измерения размера (Bytes, KB, MB, GB или без вывода);
- подсчёт общего количества найденных файлов.

## Установка
1. Убедитесь, что установлен Python 3.8+
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск
```bash
python folder_scanner.py
```

После запуска выберите папку и нужные единицы измерения, затем нажмите
**Start Scan**. Результат будет сохранён в файл `res.txt` рядом с
программой.

## Сборка исполняемого файла (необязательно)
Для создания самостоятельного исполняемого файла можно использовать
[PyInstaller](https://www.pyinstaller.org/):
```bash
pyinstaller --onefile folder_scanner.py
```
